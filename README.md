# X4 Civilian Economy (Mod)

## Summary

X4 mod that adds a civilian economy to the game.

## Documentation

- [User Manual](/docs/MANUAL.md)
- [Developer Documentation](/docs/DEVELOPMENT.md)

## Contributing

Contributions in the form of pull requests are welcome.

## Internationalization

The mod is primarily developed in English and automatically translated into all
default game languages. If you spot any translation issues, I'll gladly accept
pull requests.

## Feedback and Issue Reports

Open a GitHub issue or leave a post on the
[Nexus mod page](https://www.nexusmods.com/x4foundations/).

## Declaration of AI usage

Development of this mod makes heavy use of AI, based on the excellent [X4 Claude
Modding Tool](https://www.nexusmods.com/x4foundations/mods/2186) by ttyyygggg. I
simply wouldn't have had the time to build this otherwise. Only use if you are
ok with this. Expect "claude-isms" in code and comments!
